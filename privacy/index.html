개인정보처리방침

앱 이름: 타이핑 마스터 (Typing Master)
패키지: com.jia.typingmaster
시행일: 2026년 9월 28일
🔒 핵심 요약
이 앱은 어떤 개인정보도 수집하지 않습니다. 회원가입도, 로그인도, 광고도 없습니다. 게임 기록은 오직 사용자의 기기 안에만 저장됩니다.

1. 수집하는 개인정보

없음. 이 앱은 다음을 포함한 어떠한 개인정보도 수집·저장·전송하지 않습니다.

  • 이름, 이메일, 전화번호, 생년월일 등 신원 정보
  • 위치 정보, 연락처, 사진, 파일
  • 광고 식별자, 기기 고유 식별자
  • 사용 기록, 접속 로그, 분석 데이터

2. 기기 안에 저장되는 정보

게임을 편리하게 이용하기 위해 아래 정보가 사용자 기기의 로컬 저장소(localStorage)에만 저장됩니다.

  • 게임 기록 (점수, 정확도, 도달 레벨, 별점)
  • 설정 값 (효과음, 진동, 화면 자판 표시 등)
  • 사용자가 직접 추가한 단어 목록

이 정보는 외부 서버로 전송되지 않습니다. 앱이나 브라우저 데이터를 삭제하면 함께 삭제됩니다.

3. 제3자 제공 및 위탁

없음. 수집하는 정보가 없으므로 제3자에게 제공하거나 처리를 위탁하지 않습니다.

4. 광고 및 분석 도구

사용하지 않습니다. 광고를 표시하지 않으며, Google Analytics 등 어떠한 분석 도구도 넣지 않았습니다.

5. 네트워크 사용

이 앱은 게임 화면을 불러오기 위해 웹사이트(gyumeeroh-byte.github.io)에 접속합니다. 한 번 실행한 뒤에는 오프라인에서도 동작하도록 기기에 캐시를 저장합니다. 이 과정에서도 개인정보는 전송되지 않습니다.

웹사이트는 GitHub Pages를 통해 제공되며, 호스팅 사업자인 GitHub가 접속 기록을 처리할 수 있습니다. 자세한 내용은 GitHub 개인정보 처리방침을 참고하세요.

6. 아동의 개인정보

이 앱은 만 14세 미만 아동을 포함한 모든 사용자로부터 개인정보를 수집하지 않습니다. 따라서 아동의 개인정보를 별도로 관리하지 않습니다.

7. 앱 권한

이 앱은 카메라, 위치, 연락처, 저장공간 등 어떠한 민감한 권한도 요청하지 않습니다.

8. 방침의 변경

이 방침이 변경되면 이 페이지에 게시하고 시행일을 갱신합니다. 중요한 변경이 있는 경우 앱 또는 스토어 등록정보를 통해 알립니다.
